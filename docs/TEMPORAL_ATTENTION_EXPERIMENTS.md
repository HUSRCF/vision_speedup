# 时间注意力实验：2026-10-28

正式采用的 V2 仍为 **316.774396 秒**，五项历史有效运行合计 **889.570845 秒**。下列候选均未替换正式代码或 `results/runtime.log`、`results/result.json`。

原始 16 帧 FP32 时间注意力使用 4 个 warp。针对五种实际形状，仅把 launch 改为 1 个 warp：微测六种输入状态下，QK、softmax 概率和最终输出的 int32 位模式均一致；各形状六对计时也均更快。原始 110 个 Triton JIT 函数体全部保留。

随后分别捕获完整 decision/world 图。每段检查原始输入、新输入，以及 570 个 Linear 和 782 个 FP32 GroupNorm/LayerNorm 参数修改、清零、恢复，共六种情况。三个最终输出均逐位一致，权重恢复后基线恢复逐位一致，RNG 不变。六对整段计时的中位数分别节省 **1.535492 ms**、**1.602036 ms**；这只是实际模型配对诊断，并非正式成绩。

完整 V2 在 GPU 0 上跑完 11 轮、每段 50 个 DDIM 步，结果 **317.385042 秒 / PSNR 29.675324786 dB**，23 个 MP4 的 SHA256 与当前正式版本全部相同。完整运行未受外部 GPU 进程污染，但比现有最佳慢 **0.610646 秒**，因此未采用。世界模型 CUDA 阶段减少 0.771575 秒，decision 阶段增加 1.420435 秒。单次正式总耗时不足以把这种差异完全归因于某个 kernel；不能以微测或配对诊断代替最终工作量验证。

原始证据位于 [`results/temporal-native-w1-20261028`](../results/temporal-native-w1-20261028)。生产候选仅改主机 launch 策略，并有 V2、形状、依赖和原生回退检查；没有减少步数、轮数或帧数。

另一个未采用的候选把时间注意力的 QK 和 PV 改为缩放 FP16 的三个补偿乘积，保留原始 FP32 softmax 树、指数和除法。单个 CTA 内出现过大或过小的非零 Q/K/V 时，两个乘积均回退到原始 IEEE FP32。微测五种实际形状通过 FP64 误差门槛且六对计时均更快，但输出通常不逐位一致。真实模型两段的六种状态检查均通过宽松误差门槛，最大相对误差分别约 2.1×10⁻⁴、5.4×10⁻⁵，配对计时中位数分别节省 1.978363 ms、2.499069 ms。完整 V2 视频质量测试已在 GPU 3 启动，不能称为视频质量通过。相关微测数据为 `results/temporal-compensated-209-report.json`。

vendor GEGLU 补偿方案仅有一个 C640 主分支配置通过既定数值门槛且六对计时均更快，中位数节省约 0.170 ms；其余配置不能概括为有效。此结论来自实际几何形状的合成输入，尚无实际模型或视频验证。

更大范围的后续方向仍为多条件 cross-attention 融合和主干补偿 GEMM。分支应保留各自 softmax、动作 mask、FP32 累加顺序与反馈语义。r3 采集正在增加明确的阶段过滤，尚未发布其结果。
