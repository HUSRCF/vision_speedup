# Z1、双臂堆箱、清理铅笔的双卡加载对照

2026-10-29，三个分项均已使用原63文件双卡完整内部块分片。本轮将G1已验证的精确权重广播移植到这三个分项，完成三组同GPU对的完整原版／新版对照。**只有较小的单组收益，未采用，没有替换正式双文件。**

当前正式五项全部使用两张A800，分项合计765.731042秒，49轮、103视频。其来源仍为Z1／双臂堆箱／清理铅笔63文件、V2 225文件及G1 68文件。

## 改动范围与成本

保留原63文件中的全部推理数学辅助实现。仅修改原并行runtime、增加`nccl_root_model_move.py`，并在原`model_to_gpu`计时范围内替换一次`model.cuda()`接点。广播实现与G1已采用68文件版本及其第三轮合成资格测试逐字相同。

rank0从CPU搬运原dtype的权重，NCCL广播到rank1。每个张量起点256字节对齐，保留原shape、连续stride、Parameter对象和别名，末尾调用标准`.cuda()`刷新Lightning设备状态。不支持的布局走原生`.cuda()`回退；本轮三个真实模型均未回退。加载、分配、通信初始化和退出都在原进程计时内，没有计时外预加载。

| 分项 | 原model_to_gpu s | 新model_to_gpu s |
|---|---:|---:|
| Z1 | 3.514885 | 3.018551 |
| 双臂堆箱 | 3.554692 | 3.127723 |
| 清理铅笔 | 4.071061 | 2.731938 |

该方案减少了加载时间，但进程收益受其他阶段波动影响。NVML采样峰值显存从每卡29234 MiB增加到31060 MiB；忙碌样本SM频率中位数约1380～1410 MHz，采样最高温度72°C。这些是整次guard的观测，不能据此声称温度导致或没有导致降频。

两个分项在不同GPU对上并行推理，并错开模型加载。双臂原版前两次尝试被全程上下文监控发现外来进程，自动排除并终止自身尝试；第三次通过全程监控后才进入表格。没有终止外部进程或跳过GPU空闲检查。

比赛机home只余约148 KiB，1 GiB的`/var/tmp`约余103 MiB，额外重复源码准备因128 MiB预检查而停止，未修改该存储门槛。完成已有准备的候选后停止扩展本轮重复测量。没有删除其他任务或历史证据。
