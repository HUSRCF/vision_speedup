# 更大范围的并行实验：2026-10-28

正式采用的 V2 仍为 **316.774396 秒**，五项历史有效运行合计 **889.570845 秒**。与用户提供的 653.75 秒快照相比，相差约 235.82 秒；其中 V2 相差约 111.10 秒。本页实验未替换正式源码或提交文件。

## 为什么转向两张 GPU

当前[参赛手册](../problem/PARTICIPANT_HANDBOOK.md)“可尝试方向”明确列出分项内部多 GPU 并行。各实验明确使用两张 A800，不能作为单卡加速结果。交互轮次存在状态和图像反馈依赖，仍逐轮执行；没有减少轮数、50 个采样步或 16 帧。

两卡 P2P 测得约 184 GB/s；每卡独立 CUDA Graph 可并行，但同进程的统一跨卡 Graph 捕获失败。因此采用两进程、每进程一张可见 GPU、每进程独立 Graph，通过捕获在图中的 NCCL 交换结果。单卡可见拓扑也保留了原始输入缓存的 RNG 检查。

启动环境必须保留 `team07_env.sh` 的 `PYTHONHASHSEED=123`。缺少这一变量时，原有 Kahan kernel 的编译指纹检查失败，模型没有运行成功；没有取消或放宽该检查。补齐原环境后，两张卡上、NCCL 初始化前后的 14 项指纹全部匹配。

## 完整 world denoiser 检查

单独把 C640 GEGLU 分配到两卡，随后 all-gather 两份 Half 中间结果：单算子合成测试更快，但真实完整 world denoiser 反而慢约 0.93/4.59 ms，故关闭该路径。

随后将 **20 个 C320/C640 FFN** 的 GEGLU 和最终残差投影一起拆分，每卡计算独立的一半输出行，只在 FFN 末尾 all-gather 一份 FP32 输出。保留原 shader、K64 累加和舍入顺序、完整逻辑形状、原始缓存 owner、权重版本与设备 Count 分支。三个最终输出在原始输入、新输入、570 个 Linear 和 782 个归一化 affine 参数修改、清零、恢复的六种检查中全部逐位一致，RNG 与恢复后的基线也一致。

包含 NCCL 通信的六对完整 world denoiser 计时全部加速，两 rank 的节省中位数分别为 **13.157883 ms / 9.347595 ms**。这是每次模型前向的配对诊断，**尚无完整 11 轮 V2 总耗时或视频 PSNR 结论**，不能直接当作正式成绩。需要继续扩大覆盖并检查双模型加载、Graph 构建和通信初始化的完整成本。

精确对应上述证据的代码位于 [`validated-c320-c640`](../experiments/nccl-ffn-209/validated-c320-c640)。[`expanded-pending`](../experiments/nccl-ffn-209/expanded-pending) 是扩大到 C1280、decision FFN 和时间卷积的实验代码，尚未完成验证，不是同一已通过实现。扩大到 32 个 world FFN 的首轮被外部 GPU 进程打断；其时间不采用，后续通过锁和 NVML 检查等待干净设备重测。

两卡采样窗口约 34–41°C、核心 1410 MHz，见证据中的 `telemetry-window-only.json`；仅代表该窗口，不能替代完整运行的温度、功耗和频率记录。

## 其余四项与精度失败记录

Z1 只对不会回灌下一轮的 world 视频帧使用缓存 Half VAE、批量解码，反馈帧保留原始解码器、原始精度及 TF32 标志。完整 12 轮、25 个视频测得 **172.482165 秒 / PSNR 40.078446 dB**，比现有 175.139262 秒快 **2.657097 秒**，独占检查通过。尚未完成五项 103 视频汇总复核，未替换正式材料。扩展到 decision 展示视频的版本还在验证。

Z1 cuDNN 搜索加 Conv2d 的候选为 181.004042 秒；channels-last 候选为 209.011749 秒，均较慢。不是有效优化。

两条降低精度的完整 V2 路线均失败：时间注意力三个补偿乘积为 **316.512409 秒 / 22.759869 dB**；空间 Transformer 前 14 帧 Half dense/attention、FP32 norm/残差、后 2 帧保留原路径为 **311.596807 秒 / 21.895641 dB**。它们都完成规定工作量并独占运行，但不满足严格大于 25 dB 的质量要求，不采用。
