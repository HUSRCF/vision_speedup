# G1 双卡完整轨迹的只读观测

当前正式五项均使用两张 A800，分项合计738.805454秒；非V2四项合计480.860249秒。本实验继续研究G1的时间步复用，没有替换正式结果。

## 完整运行与接入保真

在70文件全刷新对照上，只新增普通Tensor特征观测模块及入口安装／收尾调用。原70个推理模块SHA全部不变；原有原生数学与绑定辅助代码不变，不新增原生参数或地址检查。

GPU0／1运行完整11轮，每轮decision／world各50步，两阶段各550调用，保留原两张全刷新图。23视频与原68文件正式G1及另一rank的SHA全部一致，PSNR为26.107156332dB。带采集的进程时间166.350297秒，仅作为诊断记录，不作为提速成绩。

采集`output_blocks.2/.5/.10`三个边界，对应deep7／13／23。每个边界在GPU内保存100个FP16槽位，两阶段各50个；跨轮覆盖，总驻留5,898,240,000字节／rank。非连续输出先转连续布局。只导出标量误差、形状与校验证据，不导出特征或权重。

每阶段完整刷新后，在当前轮的真实轨迹上模拟三个复用窗口`[10,40)`、`[20,40)`、`[30,40)`，隔步预测；历史仅使用模拟刷新位置。比较最近特征、两刷新线性外推、三刷新二次外推，FP32计算后舍入为原FP16。两rank各5940行标量统计完全一致。

## 结果及适用边界

以下是`[20,40)`窗口、每组110个预测位置的特征相对L2误差中位数：

| 阶段／边界 | 最近特征 | 线性外推 | 二次外推 |
|---|---:|---:|---:|
| decision deep7 | 0.06818 | 0.08155 | 0.11579 |
| world deep7 | 0.07059 | 0.08379 | 0.12055 |
| decision deep13 | 0.05560 | 0.06605 | 0.09230 |
| world deep13 | 0.05686 | 0.06732 | 0.09367 |
| decision deep23 | 0.15359 | 0.18985 | 0.26085 |
| world deep23 | 0.15446 | 0.19002 | 0.26216 |

这些结果支持降低G1无条件高阶外推的优先级：该窗口下外推的组内中位误差更大。但观测基于全刷新参考轨迹，**没有近似反馈误差**，不能据此推断完整视频PSNR，也不能直接推广到其他分项。修改刷新策略仍需独立完成全部轮数、50步和官方质量验证。
