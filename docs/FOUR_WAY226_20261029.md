# V2 四卡独立行分片：模型验证

本轮以正式 225 文件、两张 A800 的实现为源代码基线。当前正式 V2 仍为 **257.945205 秒 / PSNR 29.675324786 dB**，五项 **771.314275 秒**。本文模型计时不构成新的完整成绩。

## 路由范围

将已有空间帧、独立时间位置、FFN 行和时间卷积输出通道从两份扩大为四份。保留完整外层形状、完整五维 GroupNorm、每个空间位置的全部 16 个时间步、原 JIT 算术、K 顺序、补偿和舍入边界。原生 attention 使用各 rank 对应的全局 4 帧和 mask。

原生 ResBlock 与 world CO 卷积继续使用原来的两份网格和绑定，不扩展其 CUDA 参数访问：rank 0/1 和 2/3 分别形成一组。输出／本地片段元素数之比为 2 时使用所属组，为 4 时使用全局组。未增加块内汇合次数。

新增 `four_way226_groups.py`，合计 226 个 Python 源文件。各 rank 为新行形状使用独立可执行缓存；CUDA Graph 生命周期结束后才销毁所属 NCCL 组。

## 正确性与计时

CPU 检查覆盖 40 个用例，包括全局帧 mask、完整时间行、分组 QKV、`init_attn` 延迟汇合及 2/4 分片选择。没有初始化 GPU。

Decision 和 world 均在四张空闲 A800 上完成六组状态、三个输出的严格逐位检查。覆盖 570 个 Linear、782 个 norm、568 个 Conv1d/2d/3d master 参数的改变、清零和恢复；恢复基线与 RNG 检查通过。

| 阶段 | 四卡候选各 rank 的前向中位数 ms | 新测正式 225 两卡 rank 0/1 ms |
|---|---|---|
| Decision | 151.0354 / 150.9929 / 151.0149 / 150.9990 | 174.8808 / 174.8654 |
| World | 185.1796 / 185.1740 / 185.1581 / 185.1822 | 225.4034 / 225.4029 |

**比较边界：**模型诊断的六对交替计时，baseline 是安装分片控制器之前捕获的原始 209 数学路径，虽然源代码树来自 225。它不是已采用的两卡 225 执行图。表中两卡数字来自另一组新测量，两者差值不能当作配对实测收益，更不能直接外推为完整进程收益。

Decision 第一次尝试检测到其他 GPU context，已排除，守护程序仅结束自己的进程组；相同冻结源码第二次通过。World 第一次通过。全程保留频率、温度和 context 监控。

完整首跑已执行原始 50 步、11 轮及 23 视频，**260.270918 秒 / PSNR 29.675324786 dB**。三个辅助 evaluator 均退出 0，所有视频与 rank 0、原正式 V2 的 SHA 相同。三个辅助 evaluator 的启动、初始化、图捕获、输出比较和退出均在 rank 0 原 process timer 内。

首跑**没有通过新包装器验收，未采用**：新增 guard 错误地要求五项校验脚本整体退出 0，而 V2-only 运行缺少另外四项，会按原规则返回非零。保留原始失败、完整结果及 guard，不倒改为成功。r2 仅修改 guard：要求 V2 自己的完整轮数、视频数、执行证据和 PSNR 通过，并记录真实退出码；生产 226 源码与 r1 完全相同。五项正式发布仍须另做新 103 视频汇总。当前等待空闲 GPU 完成同期两卡对照及修复后四卡复跑，不能把首跑当成已经证明加速的结果。

首跑中活跃频率与温度见 [`telemetry-summary.json`](../results/aggressive-20261028/four-way226/full-candidate-r1/telemetry-summary.json)。启动与捕获开销计入完整时间；已有编译缓存的后续复跑也会保留独立记录，不能只报告稳态前向。

公开入口 [`reproduce/run_v2_four_way226.py`](../reproduce/run_v2_four_way226.py) 的 `--prepare-only` 已在比赛机通过 CPU 重建：226 源码和全部计时资源哈希一致，系统盘空闲字节未变。运行仍需授权模型、输入、四张空闲 GPU 及已验证私有 NCCL tmpfs 适配器配置；入口默认不替换正式材料。

```bash
python3 reproduce/run_v2_four_way226.py --gpus 0,1,2,3 \
  --workdir /var/tmp/your-unique-four-way226-run --prepare-only
```

## 新测 225 热点

新测两卡 225 world 的 NCCL 汇合约 20.676 ms／前向、130 次；decision 约 10.294 ms、55 次。这支持继续扩大已有汇合边界内部的计算覆盖，并提示四卡通信成本必须完整计入。

原生 attention、`init_attn` FFN、world 时间块、decision 时间块及筛选后的 world CO 卷积已分别在 219、220、221、223、225 中验证。对旧 218 的审阅建议不能直接视为当前仍未实现的缺口。
