# 非 V2 双卡：按任务扩大时间步复用窗口

本轮在清理铅笔和双臂堆箱的现有双 A800 版本上独立验证 `[20,46)`。五项此前已经全部使用两张 GPU；这里改善的是现有分片计算与跨步特征复用的组合。Z1 的通过结论没有直接用于其他任务。

| 完整运行 | GPU | 轮数／视频 | process_wall_s | PSNR dB | 结论 |
|---|---|---|---:|---:|---|
| 铅笔 stop46 候选 | 0／1 | 8／17 | 90.806070 | 25.796786028 | 质量通过 |
| 铅笔原 stop40 同卡对照 | 0／1 | 8／17 | 94.312247 | 26.798606240 | 视频 SHA 与原正式完全一致 |
| 双臂 stop46 候选 | 0／1 | 7／15 | 83.370978 | 24.654727020 | 质量失败，不采用 |

铅笔这一组完整候选／对照省 **3.506177 秒**；只有一组同卡比较，没有多组独立配对结论。历史正式铅笔为 92.232482 秒，候选比历史少 **1.426412 秒**，两种差值不能混用。两项候选均完成原始工作量，两 rank 视频 SHA 相同。

## 实际改动和分工

从各任务自己的正式源码构建，而不是把 Z1 的协调器直接套用过去：

- 铅笔保留 66 文件版本，包括末端 5 个残差块空间部分的 8／8 帧双卡分工；时间卷积和五维归一化仍看到完整 16 帧。
- 双臂保留 65 文件版本，不接入尚未证明稳定净收益的尾部残差块分帧。
- 两项都只将入口的 `stop:40` 改成 `stop:46`，以及对应协调器的每轮复用次数断言 `10→13`。预测数学、精度、缓存辅助模块、采样器、各任务原有分片和有效参数均不变。

每阶段每轮仍有全部 **50 次 DDIM 更新**。在 `[20,46)` 内间隔 2 复用 23 个深层父模块，每轮 13 次预测、37 次完整刷新；末尾 4 步完整刷新。两个真实历史刷新用于外推，浅层和 action／state head 持续执行。每阶段两张卡共同执行原计算分片，完整／复用图各自使用原有汇合边界。

| 项目 | 铅笔 | 双臂 |
|---|---:|---:|
| 每阶段调用／刷新／复用 | 400／296／104 | 350／259／91 |
| 每阶段完整图／复用图汇合数 | 38／4 | 33／3 |
| 两阶段 Transformer 图捕获数 | 72 | 72 |
| 附加尾部残差块捕获数 | 12 | 0 |

两项的完整视频结果相反，说明复用窗口需要按任务验证；通过局部预测器自检、减少计算量或在 Z1 通过都不能替代最终闭环 PSNR。

## 证据与复现

精确源码和守护脚本在 [`experiments/nonv2-stop46`](../experiments/nonv2-stop46)，完整原始日志／JSON、两 rank 控制报告及遥测在 [`results/aggressive-20261029/nonv2-stop46`](../results/aggressive-20261029/nonv2-stop46)。首个双臂尝试只等待 GPU 2／3，没有启动 benchmark；确认只有自己的两个等待进程后终止等待，保留原源码和全新输出状态，迁到 0／1。等待终止证明与第二次实际运行的源码身份均保留，不把等待尝试记作成绩。

公开重建在比赛机上隐藏全部 GPU，逐文件核对 66／65 文件和计时资源 SHA，通过原始 3600 次仿射预测检查、真实 23 父模块下铅笔 800／双臂 700 次调用检查，以及词法缓存恢复检查。铅笔另通过分帧／完整时间边界 CPU 检查。实际 GPU 自检和完整视频质量单独记录。


候选／对照的峰值显存均为 31,600 MiB／卡；候选最高温度 59／68°C，对照 60／71°C。忙碌样本的 SM 频率中位数均为 1410／1395 MHz。原始遥测和统计保留，不由温度或频率推断计时差的原因。
