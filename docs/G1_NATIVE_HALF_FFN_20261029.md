# G1：保留原生 Half 内核的 FFN 分片

当前正式 G1 仍为 **160.897537 秒 / PSNR 26.107156332 dB**，五项合计 **771.314275 秒**。本页记录新候选的模型筛选；完整 11 轮候选已启动，尚不据此替换正式材料。

上一轮 attention-only 在六状态下逐位一致，但没有通过两个阶段的配对速度门槛。更早的全内部块 G1 候选虽然更快，完整 PSNR 只有 19.081776 dB。这次保留原生 Half GEMM 的完整形状、描述符、编译函数和 K 顺序，仅分片独立行；GEGLU 保留完整 N constexpr、Half 舍入边界，并核对实际编译 CUBIN 的 SHA256。

## 资格与边界

先用独立合成输入测试实际 Torch 拥有的输入、权重及输出张量。输入和输出具有两倍行数的实际分配，检查本 rank 的有效行、未计算行及尾部 canary。只有与拥有张量起始位置唯一匹配的输入、输出才允许绑定；driver 参数、地址和偏移不导出。

10 种实际 FFN GEMM 形状中，9 种在两个 rank 的六状态测试通过逐位检查。`M=640,N=10240,K=1280` 的 producer 原行网格为 5，不能安全减半，未纳入候选。因此每阶段覆盖 **31 / 33 个 FFN**，包括 512 通道 `init_attn`，每个 FFN 只在 consumer 结束后汇合一次。另两个最小 FFN 保留原路径。

真实模型使用当前正式 G1 的 59 文件基线、官方 frame_stride=6 和原运行参数，保留 FP32 feedback head。132 个 FFN master 参数经过输入变化、权重变化、清零和恢复等六状态检查；三个输出均逐位一致，RNG 和恢复检查通过。没有依据 Z1 的质量结果推断 G1。

## 模型配对结果

同一进程、同一 GPU 对交替测试六对，每个条件取七个样本中位数。下面是完整 denoiser 前向，包含候选的 31 次汇合；这些时间不包含完整进程启动、加载及视频写入。

| 版本 | Decision 两 rank 中位节省 | World 两 rank 中位节省 |
|---|---:|---:|
| r1：原生 GEMM 行网格 | 2.200066 / 3.689472 ms | 4.186115 / 2.578430 ms |
| r2：再分片原 GEGLU | 3.739647 / 5.341183 ms | 5.858818 / 4.372997 ms |

按每对中“最快单卡 baseline 减最慢 candidate”计算，r2 的保守中位节省分别为 **3.719170 ms、4.364292 ms**，两个阶段的六对均为正。乘各 550 次约为 4.45 秒的模型外推，完整收益仍须实测。

## 完整候选

64 文件候选在原 59 文件上增加五个模块；原数学源码保持原样，评价入口仅增加四个计时内生命周期接点。两个阶段分别持有自己的原生绑定，退出时先恢复绑定再销毁 CUDA Graph，随后关闭 NCCL。第二个进程启动、首次 warm-up、图捕获、绑定、额外初始化 replay、输出及退出均进入原 process timer。

完整 G1 使用 GPU 0/1，11 轮、23 视频；空闲锁及整次外来 context 检查、温度／频率遥测启用。完整视频质量及正式 103 视频汇总通过之前，现有 `/GPU` 双文件保持不变。
