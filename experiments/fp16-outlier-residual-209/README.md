# FP16 主项、缩放 INT8 残差与 Half 离群通道保护

这些是固定原始 209 源码后的独立诊断，没有替换正式实现。所有量化仅用于十个中间 world FFN 的残差项，原 Half 主项与 FP32 输出保留。

- `micro-r1`：从 INT8 值和尺度最大值中移除固定首样本选出的离群 K 通道，在 GEMM 内用 Half 计算其残差；20 个新配置、三个原补偿对照。
- `dense-micro-r2`：将离群值打包为连续 Half 矩阵，融合进 INT8 pack；同样 20 个新配置、三个对照。保护 256/5120 通道时相对误差 3.25948e-6，中间形状每次中位省 0.067379 ms。
- `model-r1`：256 通道版本的完整 world 前向检查；570 Linear、782 norm、192 Conv2d 参数修改／清零／恢复，三个最终 FP32 输出记录近似误差并通过 gross gate，完整前向中位省 0.440826 ms。每次输入和权重打包均计入。
- `full-quality-r1`：**321.720411 秒 / PSNR 25.743336922 dB**，完整 11 轮、23 个视频通过质量门槛，但没有证明完整进程加速，未采用。别名生成器验证原始文件与生成文件 SHA256，hook 位于原计时器之后。
- `per-layer-r1`：十个实际投影的逐层统计，30 个近似配置、10 个求和顺序对照、10 个原补偿对照。保护 256 通道时，残差 GEMM 相对误差为 2.97e-6～3.89e-6；仅重排完整 Half 残差求和的误差为 2.09e-7～2.31e-7。

完整质量结论只对应已测试的 256 通道配置，其他近似配置仍需完整 PSNR 检查。需要比赛授权模型、原依赖和原 209 文件版本；各目录脚本按原模型诊断参数在独立副本运行，flags 与源文件 SHA256 一并保留。该目录不含模型参数、激活张量或视频。

原始统计与源码证明见 [`results/aggressive-20261028/fp16-outlier-residual-209`](../../results/aggressive-20261028/fp16-outlier-residual-209)，测量解释见 [`docs/FP16_SCALAR_EXPERIMENTS_20261028.md`](../../docs/FP16_SCALAR_EXPERIMENTS_20261028.md)。
